BigExp¶

Java class: edu.duke.cs.osprey.tools.BigExp

A ridiculously simplistic and naive way to have floating point values with larger exponents than +-300 ish but also have fast performance for multiply and max (BigDecimal is relatively slow)

The BigExp number type consists of a floating point component (fp), and an exponent component (exp). fp is conditioned so its decimal exponent lies within [-100,100], with any overflow saved in exp.

Benchmarking indicates BigExp is roughly 30x faster than BigDecimal multiplication and roughly 2.4x slower than native double multiplication
