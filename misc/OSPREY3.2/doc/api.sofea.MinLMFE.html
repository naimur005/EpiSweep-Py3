MinLMFE¶

Java class: edu.duke.cs.osprey.sofea.MinLMFE

Finishes SOFEA computation when we’ve found the best K sequences that minimize an LMFE objective function.

This is a Java class which has been exposed to the Python API. For more information on how to call constructors on Java objects, see the tutorial: Accessing Java Classes from Python.

The best desired precision for a state free energy.

MinLMFE.stabilityFunction¶

A function to represent the stability of a sequence. Used for pruning sequences w.r.t. the wild-type sequence.

Type:edu.duke.cs.osprey.confspace.MultiStateConfSpace
MinLMFE.stabilityGap¶
A sequence is stable iff:
stability(sequence) <= stability(wild-type) + gap

for at least one value in the uncertainty ranges of the stability functions. The gap is in free energy units (Kcal/mol).

Type:float
