CoordsList¶

Java class: edu.duke.cs.osprey.confspace.compiled.CoordsList

A supremely efficient representation for atomic coordinates.

Optimized for lookup speed and read/writes to coordinates.

Does not provide any information whatsoever about atom names, atom elements, molecules, residues, bonds, etc.
