RCTuple¶

Java class: edu.duke.cs.osprey.confspace.RCTuple

An n-sized tuple for holding pairs of design positions with their corresponding discrete adopted conformation.

Positions refers to the indices in the molecule which are being designed

Conformation refers to the index into a set of discrete conformations adoptable by a design position. A residue can usually adopt multiple conformations, discretely known as rotamers.
