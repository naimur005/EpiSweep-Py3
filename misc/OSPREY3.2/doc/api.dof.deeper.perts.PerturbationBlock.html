PerturbationBlock¶

Java class: edu.duke.cs.osprey.dof.deeper.perts.PerturbationBlock

In DEEPer, perturbations don’t necessarily commute We’ll put them into “perturbation blocks,” which do this way, when we want to apply a parameter value for a perturbation, we can appropriately handle any perturbations that come after it

Note: All sidechains within a perturbation block will be idealized (in the C-beta sense) since the original sidechain conformations are no longer valid for perturbed backbones
