ConfSpaceIteration¶

Java class: edu.duke.cs.osprey.confspace.ConfSpaceIteration

An interface to a conformation space that only exposes enough information to iterate over design positions and conformations.

But it doesn’t reveal details of how the conformation space is stored, how forcefields are configured, or how atomic coordinates are defined.
