LUTEGMECFinder¶

Java class: edu.duke.cs.osprey.lute.LUTEGMECFinder

Just like SimpleGMECFinder, except it doesn’t use lower bounds on conformation energies at all. Instead, this GMEC finder assumes LUTE energies are the minimized energies, and enumerates the confs in order of LUTE energies using A* search.
